## Зафиксированные результаты этапов

- Backend переведён на .NET 10, тестовые контуры используют NUnit.
- Сформированы отдельные сборки Unit, Integration и E2E; browser E2E использует Playwright.
- Добавлены PostgreSQL Testcontainers, миграции, воспроизводимый seed и API-контракт.
- Frontend реализован на React/Vite/TanStack Query; график вынесен в lazy chunk.
- OpenTelemetry экспортирует traces в Jaeger через Compose.
- Полный аудит оформлен в `docs/audits/full-audit.md`.
- Пользовательская документация находится в `docs/user-guide.md`.
- QA-пакет находится в `docs/qa/`.
- GitHub Actions находятся в `.github/workflows/ci-cd.yml`; CI проверяет код и Compose,
  CD публикует образы backend/frontend в GHCR после успешного push в `main`.
