# Пакет QA-артефактов

Эта папка содержит материалы для ручного и автоматизированного контроля
Sales Performance Dashboard.

## Состав

- [План тестирования](test-plan.md) — объём, уровни и правила входа/выхода.
- [Каталог тестовых сценариев](test-cases.md) — шаги, данные и ожидаемый результат.
- [Матрица трассируемости](traceability-matrix.md) — связь требований и проверок.
- [Регрессионный чек-лист](regression-checklist.md) — быстрый повторный прогон.
- [Отчёт о выполнении](test-execution-report-2026-09-25.md) — фактический результат последнего прогона.
- [Шаблон дефекта](defect-template.md) — единый формат регистрации проблем.

## Быстрый старт QA

1. Запустить `docker compose up --build` из корня проекта.
2. Открыть <http://localhost:3000>.
3. Выполнить регрессионный чек-лист.
4. Запустить автоматические проверки:

   ```sh
   dotnet test backend/SalesDashboard.slnx --no-restore
   npm --prefix frontend run build
   ```

Интеграционные и backend E2E-тесты требуют работающий Docker daemon.
Browser E2E требуют установленный Chromium и запущенный frontend.
