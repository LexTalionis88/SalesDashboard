SQL и преобразование дат проверять на PostgreSQL: in-memory provider не подтверждает реальное поведение PostgreSQL. Не нужен целевой процент покрытия; важна проверка бизнес-результата. Итоговый протокол должен записывать выполненные проверки, среду, результат и известные ограничения без заявлений об отсутствующих проверках.
