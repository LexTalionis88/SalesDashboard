# Frontend

Зарезервирован каркас React + TypeScript приложения. `package.json`, lock-файл, entry point, сборочная конфигурация и Dockerfile ещё не созданы.

| Каталог | Назначение |
| --- | --- |
| `src/app` | Инициализация приложения, общая композиция, провайдеры и стили |
| `src/features/dashboard` | Период, KPI, рейтинг, графики, категории, продукты, последние продажи |
| `src/shared/api` | Типизированные DTO, HTTP-клиент, единая обработка ошибок |
| `src/shared/ui` | Общие элементы UI, skeleton, error и empty state |
| `tests` | Проверки смены периода, режима рейтинга и состояний |

Библиотеки и версии выбираются по D-10. Расчёт KPI, сортировка рейтинга и фильтрация продаж должны выполняться backend. Обязательная область проверки UI: desktop примерно 1440×900.
